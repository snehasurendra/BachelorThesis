# BachelorThesis
Differential Diagnosis Prediction Interface for Liver Diseases, Bachelor Thesis
 - Developed a predictive model to analyze and forecast disease progression patterns. 
 - Implemented machine learning techniques, including K-Nearest Neighbors (KNN) and Sequential algorithms with Keras for deep learning.
 - Built and trained the model using Python and TensorFlow to ensure accurate clinical predictions. 
 - Deployed the system through Django framework, creating a scalable and user-friendly interface for clinical 
applications
